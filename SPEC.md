# FM Mini — SPECIFICATION 1.3.12

PURPOSE. Minimal native macOS chat app for Apple's on-device model (FoundationModels): chat in French, attach one text document, copy answers, discover the ecosystem. Nothing else. Target users: non-developers. Must work first try on a fresh Mac.

PREREQUISITES — checked by make-app.sh itself (stop with a clear French message if missing): macOS ≥ 27 (`sw_vers`), Apple Silicon (`uname -m` = arm64), Command Line Tools (`xcode-select -p`; else say `xcode-select --install`). Model availability checked by writing and running /tmp/fmcheck.swift (SystemLanguageModel.default.availability, contextSize) — never by the `fm` CLI. If the check reports ModelManagerError 1008 / "not available in this context", print "Le modèle n'est pas accessible depuis ce contexte. Lancez ce script depuis l'application Terminal." and stop. Xcode NOT required.

LAUNCH CONTEXT RULE. The on-device model is reachable from a command-line process only when its launch chain goes back to Terminal.app (or from a signed .app launched normally). Agents launched from other apps get error 1008. The autotest and the preflight must say so explicitly instead of failing silently.

BUILD. SwiftPM executable "FMMini", Swift 6, SwiftUI + FoundationModels (+ AppKit, PDFKit), no third-party dependency. No Swift macros: `@Local` wrapper over State(initialValue:) with Binding projection; ObservableObject + @Published. make-app.sh: preflight → swift build -c release → build/FM Mini.app (bundle id org.local.fmmini, CFBundleShortVersionString = version, LSMinimumSystemVersion 27.0, NSHighResolutionCapable, CFBundleDevelopmentRegion = fr, Contents/Resources/fr.lproj) → codesign --force --deep --sign - → prints the open command. Git: one commit per delivered change, working tree clean at delivery.

ICON. `Resources/AppIcon.icns` is copied to `Contents/Resources/AppIcon.icns`; `CFBundleIconFile` is `AppIcon`, and the same bundled icon appears in the Dock, Finder and the “À propos” window.

WINDOW. Portrait side-panel: default 460×760, minimum 400×560, resizable, frame remembered (frameAutosaveName), centered on first launch. Light scheme, white background. Legible at 400 px wide: no clipping; long file names wrap on two lines rather than being truncated.

MENUS AND KEYBOARD. The macOS menu bar contains, in order, FM Mini, Fichier, Édition, Présentation, Fenêtre and Aide. Fichier contains “Nouvelle conversation” (⌘N), “Ajouter une PJ…” (⌘O) and the standard “Fermer” (⌘W). Édition contains “Copier la dernière réponse” (⌘⇧C), disabled when there is no model response. These shortcuts work when the message field has focus.

FOCUS. The app owns its Tab cycle without depending on the macOS “Navigation au clavier” setting: Message → Envoyer → Ajouter une PJ… → Nouvelle conversation → Message; Maj-Tab reverses it. A disabled button is skipped. SendTextView handles insertTab and insertBacktab to move through this cycle instead of inserting a tab character. The focused button has a visible ring and Space or Enter activates it.

HEADER (outside the scroll view, centered on the window width): wordmark "FM Mini" (bold ~28 pt, tight tracking, dark grey) — no subtitle; button "Nouvelle conversation"; thin context gauge "N / M jetons" (grey < 60 %, orange < 85 %, red above), recomputed after each turn with tokenCount(for:) over the whole transcript.

LANGUAGES. L = SystemLanguageModel.default.supportedLanguages deduplicated by language code; COUNT = L.count (15 on macOS 27.2: allemand, anglais, chinois, coréen, danois, espagnol, français, italien, japonais, néerlandais, norvégien, portugais, suédois, turc, vietnamien). COUNT computed at runtime, never hard-coded.

WELCOME (conversation empty: at launch and after "Nouvelle conversation"; disappears at the first message):
- Heading "BONJOUR, QUE PUIS-JE FAIRE POUR VOUS ?".
- Centered paragraph, max width ~380 px, verbatim with COUNT substituted: "Je suis gratuit et je travaille localement sur votre Mac, sans jamais transférer vos documents dans le cloud. Je suis spécialisé dans le traitement du texte en COUNT langues (dont le français) : je sais résumer, corriger, analyser, reformuler, traduire et extraire des informations de la plupart des textes que vous me confierez. En revanche, je ne connais pas l'actualité et mes connaissances encyclopédiques sont très limitées. Essayez-moi !"
- 5 chips: "Résume la PJ en 200 mots environ." ; "Corrige l'orthographe et la grammaire de la PJ, en gardant le sens." ; "Crée un quiz de cinq questions à partir de la PJ, avec les réponses." ; "Extrais les noms, dates et chiffres de la PJ." ; "Traduire la PJ en…" (menu = L, French names, sorted; inserts "Traduis la PJ en <langue>."). If no PJ is loaded, a chip opens the file picker first; after acceptance, or with a PJ already loaded, it inserts its text with the cursor at the end without sending. Cancelling the picker inserts nothing.
- Link: "Aller plus loin →".
- At 460×760 heading, paragraph and chips visible without scrolling.

TYPOGRAPHY. All visible French strings use a narrow no-break space (U+202F) before : ; ? ! and « » spacing.

CHAT. User bubbles light grey, model bubbles white with border, ≤ 85 % width, plain selectable text, auto-scroll, ms under each model answer. Hover → "Copier" (SF Symbol doc.on.doc, 44 pt) copies plain text to NSPasteboard, shows "Copié" 1.5 s; right-click → "Copier". Streaming rendered as it arrives. "Nouvelle conversation" stays enabled during a stream and cancels it before resetting.

INPUT. Multiline field (accessibility label "Message"), 3 lines by default growing to 6 by content, Enter = send, Shift-Enter = newline. "Ajouter une PJ…" (NSOpenPanel: txt md csv json log rtf docx pdf). Hint line: "PJ acceptées : .txt .md .csv .json .rtf .docx .pdf (texte, pas de scan) — jusqu'à environ N mots", N = contextSize × 0.9 / 1.4 rounded to the hundred. "Envoyer" and "Ajouter une PJ…" disabled while streaming; "Envoyer" disabled when input is empty; send() guarded against double submission.

MODEL.
- At launch: availability; if unavailable, replace the chat by the exact reason + "Ouvrir Réglages Système" (x-apple.systempreferences:com.apple.Siri-Settings.extension).
- Fixed instruction ONLY: "Tu es un assistant. Tu réponds toujours en français, quelle que soit la langue du message. Tu vouvoies la personne."
- Without attachment: text sent as typed. With attachment: injected only in the FIRST message after loading, as "Réponds uniquement à partir du document ci-dessous.\n\nDocument « <name> » :\n<content>\n\nQuestion : <user text>"; then passive badge "PJ : <nom> (N jetons)"; later messages as typed; loading another file or another part resets the conversation, then injects the new document once; "Nouvelle conversation" clears.
- Reading: .txt/.md/.csv/.json/.log UTF-8 (non-UTF-8 → "Le fichier doit être du texte UTF-8 lisible."); empty or whitespace-only → "Ce fichier est vide."; .rtf/.docx via NSAttributedString (failure → "Ce fichier est illisible (document endommagé ?)"); .pdf via PDFKit (no text → "Ce PDF ne contient pas de texte lisible (scan) : il faudrait d'abord le passer par la reconnaissance de texte."). File > 5 Mo (5 000 000 bytes, decimal in code and message) → "Fichier trop lourd (X Mo, maximum 5 Mo)". None of these attach the file.
- Before sending: tokenCount over instructions + transcript + message vs contextSize.
  (a) File alone > 90 % of contextSize → inline card "Ce document fait N mots (T jetons). Je ne peux lire qu'environ P mots à la fois — c'est la limite de mémoire du modèle, pas un bogue. Je l'ai découpé en K parties ; choisissez celle à charger, ou posez votre question partie par partie." P = contextSize × 0.6 / 1.4. CUT RULE: sentence boundaries first (end = . ! ? … followed by space, newline or end; a paragraph break is a boundary only if preceded by terminal punctuation); whole sentences are packed into parts ≤ P words, preferring to close a part at a paragraph break once the part is ≥ 80 % of P; a single sentence longer than P is the only case split by word groups and the part carries the note "(phrase très longue coupée)". K = the number of parts actually produced. One chip per part "Partie i/K — mots a à b — « first 8 words »"; a chip loads that part (badge "<name> — partie i/K"); chips remain; nothing written to disk.
  (b) Transcript > 60 % after a turn → automatic compression: "Résume en moins de 200 mots les questions posées et les réponses données, en gardant les faits, chiffres et noms exacts. Ne résume pas le document lui-même." over all Q&A except the last two (greedy), in a separate session without the document; fresh session (same instruction); re-inject: document verbatim (if any), "Résumé des échanges précédents : <summary>", last two Q&A verbatim; grey line "Conversation compressée : N → M jetons (le document est conservé en entier)."; bubbles stay. If still > 85 % → "La conversation est pleine (N / M jetons)." with "Nouvelle conversation en gardant le document" / "Nouvelle conversation".
- Errors inline, never modal, from LanguageModelError: guardrailViolation → "Les garde-fous d'Apple ont bloqué cette réponse." ; contextSizeExceeded → "La conversation est trop longue pour le modèle : cliquez sur Nouvelle conversation." ; unsupportedLanguageOrLocale → "Langue non prise en charge." ; other → raw message.

"ALLER PLUS LOIN" WINDOW (menu Aide + welcome link): 520×720, scrollable. Intro: "FM Mini fait exprès peu de choses…" verbatim from the 1.3.9 request. Two sections, "Déjà sur votre Mac" (dictée, Raccourcis, Terminal) and "À ajouter à FM Mini avec votre assistant" (images/scans, page web, dossier de documents): exactly six cards. Each card has a title, "Ce que ça apporte :", "Vos données :" and one button. The first three buttons only open the specified local system setting or app. The last three buttons copy their verbatim development request and show "Copié" for 1.5 s. No detection, status, Process or network call exists in this window. Footer: "Rien n’est installé ni téléchargé par cette fenêtre : elle ouvre des apps déjà présentes ou copie du texte."

ABOUT. The application menu FM Mini → "À propos de FM Mini" opens one non-resizable 520 px-wide "À propos" window. It has a white background, the bundled Resources/credits.jpg image at full width with a 12 pt rounded corner and preserved proportions, then centered "FM Mini", CFBundleShortVersionString, "acromega + Claude — 2026", and the accessible-grey line "Tourne entièrement sur votre Mac avec le modèle Apple Foundation Models." No links, network calls or other content.

PRIVACY. No network call anywhere in the app. Nothing written to disk except window frame (UserDefaults) and the autotest report. No log with conversation text. Cuts in memory only. No entitlements, no permission prompts beyond NSOpenPanel.

AUTOTEST. `FMMini --autotest` (run from Terminal.app): headless, prints each check with timing, writes ~/fm-mini/autotest-<date>.txt only (inputs built in memory): (0) no-attachment question → French, no document mention; (1) "salut" → French; (2) 300-word file → faithful summary; (3) 20 000-word file → "trop long" with both numbers; PJ chips: cancellation leaves the field unchanged, a loaded PJ inserts the text without sending, and the welcome fits at 460×760 without scrolling; (8) 619-word document + 6 questions → injected once, one compression, gauge before/after, 7th answered, first question recalled; (9) bubble copy → pasteboard; (12) audit-fixtures/long-20000-mots.txt → K parts, no part ends without terminal punctuation, part 2 answered; fixtures: .docx read, scan PDF refused with the exact message, 4_9Mo accepted, 5_1Mo refused with "5,1 Mo", vide.txt refused; window: 6 cards and 3 non-empty copied requests; language count = menu count. On error 1008 print "Modèle inaccessible depuis ce contexte : lancez l’autotest depuis Terminal.app" and exit 2. The flag enables nothing else.

README (French, non-developers): prerequisites and that make-app.sh checks them; the 3 commands; signature ad hoc explained and Gatekeeper right-click → Ouvrir; what the app does; "COUNT langues (24 variantes régionales) : <list>" + "hors liste : texte sans garantie ; seule la qualité du français a été mesurée"; "Et si mon document est trop long ?"; "Ce qu'il ne sait pas faire" (compter, comparer, détecter une contradiction, dire « le texte ne le dit pas » — il restitue, il ne vérifie pas); "Plus la conversation est longue, plus chaque réponse est lente ; FM Mini la compresse automatiquement."; autotest from Terminal.app only; the "Aller plus loin" window; troubleshooting from real runs.

OUT OF SCOPE: settings, model picker, PCC/cloud, history persistence, images/OCR, multiple documents, themes, dark mode.
